═══════════════════════════════════════════════════════════════════
                          ETL FLOW SEQUENCE
═══════════════════════════════════════════════════════════════════

Step 1: INITIALIZATION
  ┌─────────────────────────────────────────────────────┐
  │ Orchestrator generates unique ETL Run ID            │
  │ Creates Logger instance with Run ID                 │
  │ Creates Extractor, Transformer, Loader instances    │
  │ Logs: "ETL process initialized"                     │
  └─────────────────────────────────────────────────────┘
                         │
                         ▼
Step 2: EXTRACT
  ┌─────────────────────────────────────────────────────┐
  │ Read from ZSALES_RAW                                │
  │ WHERE trans_date BETWEEN from_date AND to_date      │
  │   AND status = 'N' (New)                            │
  │ Count records extracted                             │
  │ Log: "Extracted X records"                          │
  └─────────────────────────────────────────────────────┘
                         │
                         ▼
Step 3: TRANSFORM
  ┌─────────────────────────────────────────────────────┐
  │ For each extracted record:                          │
  │   1. Calculate gross amount (qty × price)           │
  │   2. Apply discount rules:                          │
  │      - 10% if qty > 15                              │
  │      - 5% if qty > 10                               │
  │      - 0% otherwise                                 │
  │   3. Calculate tax (8% on gross - discount)         │
  │   4. Calculate net amount                           │
  │   5. Calculate profit margin (40% target)           │
  │   6. Categorize: HIGH/MEDIUM/LOW                    │
  │   7. Add ETL metadata                               │
  │ Log: "Transformed Y of X records"                   │
  └─────────────────────────────────────────────────────┘
                         │
                         ▼
Step 4: VALIDATE & LOAD
  ┌─────────────────────────────────────────────────────┐
  │ For each transformed record:                        │
  │   1. Validate required fields                       │
  │   2. Validate business rules                        │
  │   3. INSERT into ZSALES_ANALYTICS                   │
  │   4. UPDATE ZSALES_RAW status = 'P'                 │
  │ Handle errors gracefully                            │
  │ Log: "Loaded Z of Y records"                        │
  └─────────────────────────────────────────────────────┘
                         │
                         ▼
Step 5: COMPLETION
  ┌─────────────────────────────────────────────────────┐
  │ Calculate execution duration                        │
  │ Display summary report                              │
  │ COMMIT (if not test mode)                           │
  │ Log: "ETL process completed"                        │
  └─────────────────────────────────────────────────────┘

│ Currency:    USD               │
│ Sales Rep:   John Doe          │
│ Region:      NORTH             │
└────────────────────────────────┘
         │
         ▼
TRANSFORMATION STEPS
┌────────────────────────────────────────────────┐
│ 1. Gross = Qty × Price                         │
│    = 20 × $99.99 = $1,999.80                   │
│                                                │
│ 2. Discount = Gross × Rate                     │
│    Qty > 15 → 10% discount                     │
│    = $1,999.80 × 0.10 = $199.98                │
│                                                │
│ 3. Taxable = Gross - Discount                  │
│    = $1,999.80 - $199.98 = $1,799.82           │
│                                                │
│ 4. Tax = Taxable × 8%                          │
│    = $1,799.82 × 0.08 = $143.99                │
│                                                │
│ 5. Net = Taxable + Tax                         │
│    = $1,799.82 + $143.99 = $1,943.81           │
│                                                │
│ 6. Cost = Qty × Price × 60%                    │
│    = 20 × $99.99 × 0.60 = $1,199.88            │
│                                                │
│ 7. Profit Margin = (Net - Cost) / Net × 100   │
│    = ($1,943.81 - $1,199.88) / $1,943.81 × 100│
│    = 38.28%                                    │
│                                                │
│ 8. Category = MEDIUM (< $2,000)                │
└────────────────────────────────────────────────┘
         │
         ▼
